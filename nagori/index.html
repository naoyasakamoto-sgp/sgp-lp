03 / Notes

作品になる前に、残っていたもの。

2026.08 / PRODUCTION NOTE

AI生成曲を、NAGORIの曲へ作り直す。

AIが出した完成形を採用するのではなく、心が動いた理由だけを持ち帰る。メロディー、コード、間、Rhodesの質感を分解し、ピアノと自分の声からもう一度組み立てる。

AI版は、まだ形になっていない感情を外から聴かせてくれるラフスケッチ。

MEMORY

言えなかったことを、説明しすぎない。

作者には具体的な一日がある。リスナーには、自分の記憶を置ける余白がある。その両方を失わない言葉を選ぶ。

PLACE

街は背景ではなく、感情が起きた現場。

駅、エスカレーター、窓に映る光。仙台を観光地として撮るのではなく、誰かを見ていたことで変わった知覚として残す。

04 / About

NAGORIは、
消えていくものの
そばにいる。

誰かに見せるためではなく、
自分が確かに生きていた時間を失わないために。

NAGORIは、仙台を拠点に、言葉にならない関係、街に残る記憶、始まらなかった時間を、音楽・映像・文章として残すアーティストプロジェクトです。

大きな感動を作るより、小さな表情を見逃さないこと。結論を与えるより、聴く人の記憶が入る余白を残すこと。生成AIも使いながら、最後は自分の手と声で作品へ作り直します。

観察する削る残す説明しすぎない
