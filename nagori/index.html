04 / Notes

作品になる前に、残っていたもの。

Production Note

AI生成曲を、NAGORIの曲へ作り直す。

AIが出した完成形ではなく、心が動いた理由だけを持ち帰る。ピアノと自分の声から、もう一度組み立てる。

AI版は、まだ形になっていない感情を外から聴かせてくれるラフスケッチ。

Memory

説明しすぎない。

作者には具体的な一日がある。聴く人には、自分の記憶を置ける余白がある。

Place

街は、感情が起きた現場。

駅、エスカレーター、窓に映る光。観光地ではなく、知覚が変わった場所として残す。

05 / About

NAGORIは、
消えていくものの
そばにいる。

誰かに見せるためではなく、
自分が確かに生きていた時間を失わないために。

仙台を拠点に、言葉にならない関係、街に残る記憶、始まらなかった時間を、音楽・映像・文章として残すアーティストプロジェクトです。

大きな感動を作るより、小さな表情を見逃さない。結論より、記憶が入る余白を残す。

観察する削る残す説明しすぎない
